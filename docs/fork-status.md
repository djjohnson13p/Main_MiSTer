# Independent MiSTer Main development

This fork develops fixes and features for the MiSTer Main ARM software. It is an experimental, AI-assisted project owned by djjohnson13p, with no upstream pull requests planned. FPGA cores, the Linux image and Downloader remain separate projects.

The starting upstream revision is `2dd3662cccd45d54d3d383bf9f7d80f6f57e6d03`, fetched October 13, 2026. Development uses `independent/main`; `master` preserves the original fork baseline. The current candidate identifies itself with `-x28`; the earlier `-x1` through `-x27` candidates and their source commits remain available. `upstream-base.txt` records official `13f1de93544ca2125c286ab3545f8fa63fd2d4f6`, selected for the x28 PC-8801 integration and pristine/fork comparison. The previously accepted `00bdff0d5b985a3a929978f86f15d930954451a2` A2065/IDE integration and its x17 history remain preserved.

## Validation and next work

The x28 PC-8801 regression executes the complete actual upstream module, its original-name and width getters, actual file declarations/lifecycle, and a separately labeled complete generic-write branch above ordinary successful in-memory file/SPI models. All 57 compound cases and 435 assertions pass, and every complete observation matches pristine official `13f1de9` without dropping fields.
